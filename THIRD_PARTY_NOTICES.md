# Third-party notices

## Louis Segond 1910

The Bible text bundled in `app/src/main/assets/bible/` is the French
**Louis Segond 1910** translation. Louis Segond died in 1885 and the 1910
revision is in the public domain.

The structured JSON files were obtained from
<https://github.com/dfoerder/free-bible-translations>
(`fra/lsg1910`), which documents the source as public domain. The files were
converted to a compact per-book format for this application. No verse text was
modified.
